# BD Final Prep
Sitio estático (HTML/CSS/JS, sin dependencias ni build) para estudiar Sistemas Transaccionales y BD.

## Subir a Vercel
1. Descomprime el ZIP.
2. Opción A: vercel.com → Add New → Project → arrastra la carpeta `bd-final-prep`. Framework: "Other"; sin build command; output directory vacío.
3. Opción B (CLI): `cd bd-final-prep && npx vercel --prod`.

Para probar local: abre `index.html` en el navegador. El progreso se guarda en el navegador (localStorage).
